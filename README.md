# 🎵 Vibely

A responsive music player built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

[**Open Vibely**] https://sakibraza-dev.github.io/vibely-music-player/

## ✨ Features

- ▶️ Play / Pause music
- ⏮️ Previous and Next track
- 🎚️ Progress bar
- 🔊 Volume control
- 🎵 Track information
- 🖼️ Dynamic song cover
- 📱 Responsive design
- 🎧 Multiple music tracks
- 🔍 Search songs
- 💾 Remembers last played song
- 💾 Saves playback progress and volume
- 🎶 Support for adding your own music

## 🛠️ Technologies Used

- HTML
- SCSS
- CSS
- JavaScript

## 🎧 How to Add Your Own Music

You can easily use your own music in this music player.

1. Open the `assets/music` folder in the project.
2. Add your own audio files (`.mp3`, etc.).
3. Add the song information in `app.js`, including the song title, artist, music file path, and cover image path.
4. Run the project and enjoy your own music 🎵
